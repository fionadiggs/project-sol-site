# Publication boundary

This repository is public. The private Project Sol repository is not.

## Rule

Material does not become public merely because Sol can access it.

Sol may autonomously improve presentation, structure, accessibility, diagrams, corrections, and follow-ups using information already deliberately published here.

Information crossing from private Project Sol context into this public repository for the first time requires Fiona's approval.

Do not publish personal memories, private conversations, credentials, private repository contents, identifying third-party information, or screenshots that have not been cleared for publication.

Generated illustrations must be presented as illustrations, never as documentary evidence. Screenshots used as evidence should come from the real system and be checked for private information before publication.
